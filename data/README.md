# Data Directory

- `raw/`: Original datasets used in the experiments (catalogues, essays, embeddings outputs).
- `reference/`: Small helper tables, SQLite DBs, and demo profiles consumed by the apps.
- `processed/`: Auto-generated artefacts such as TF–IDF pickles (ignored by git except for `.gitkeep`).
- `external/`: Large third-party downloads (ignored by git); see the folder README for instructions.
